# eac_2627_prog

Repositório dedicado aos exercícios realizados em sala de aula sobre conteúdos de programação em C.

## Objetivo

Este projeto serve para reunir e organizar os exercícios práticos desenvolvidos ao longo das aulas, com foco na aprendizagem e prática dos conceitos fundamentais da linguagem C, como:

- variáveis e tipos de dados
- operadores e expressões
- estruturas de controlo
- ciclos e condicionais
- funções
- arrays e strings
- ponteiros
- estruturas e ficheiros
- algoritmos básicos de programação

## Estrutura do repositório

A organização pode variar conforme os exercícios criados ao longo do semestre, mas normalmente será algo do tipo:

```text
.
├── README.md
├── exercicios/
│   ├── aula_01/
│   ├── aula_02/
│   ├── aula_03/
│   └── ...
├── src/
│   └── ...
└── docs/
    └── ...
```

## Linguagem utilizada

- C
- Compilador GCC (ou outro compilador compatível)

## Como executar os exercícios

1. Abra o terminal ou prompt de comando.
2. Navegue até à pasta do exercício desejado.
3. Compile o ficheiro `.c` com o GCC:

```bash
gcc nome_do_exercicio.c -o nome_do_exercicio
```

4. Execute o programa:

```bash
./nome_do_exercicio
```

Em sistemas Windows, pode ser necessário usar:

```bash
nome_do_exercicio.exe
```

## Boas práticas

- manter os ficheiros organizados por tema ou aula
- usar nomes claros e descritivos
- comentar o código quando necessário
- testar cada programa antes de concluir o exercício

## Finalidade

Este repositório tem como finalidade apoiar o estudo e a revisão dos conteúdos lecionados, servindo como material de consulta e prática para a disciplina de programação em C.
